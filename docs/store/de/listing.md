## Full description (1639 / 4000)

```text
Käsekästchen ist der Klassiker für Papier und Bleistift, gemacht für Handy und Tablet.

SO WIRD GESPIELT
Zieht abwechselnd eine Linie zwischen zwei benachbarten Punkten. Ziehst du die vierte Seite eines Kästchens, gehört es dir. Eine Linie kann zwei Kästchen auf einmal schließen. Sind alle Kästchen vergeben, gewinnt, wer die meisten hat. Bei gleicher Punktzahl ist es unentschieden.

DIE VERBINDUNGSREGEL
Die erste Linie darf überall liegen. Jede weitere beginnt an einem Punkt, der schon eine Linie hat. So wachsen die Linien zu einer zusammenhängenden Kette, jeder Zug zählt und das Feld zerfällt nicht in einzelne Ecken.

SPIEL, WIE DU WILLST
• Gegen Computer: „Leicht“ wählt eine zufällige Linie. „Normal“ holt sich Kästchen, wann immer es geht, und versucht, dir keine zu überlassen.
• Zwei Spieler: Gebt ein Handy oder Tablet einfach weiter.
• Feldgröße von 2×2 bis 10×10 Kästchen: eine schnelle Runde im Bus oder eine lange auf dem Sofa.
• Wähle deine Farbe und starte die Revanche mit einem Tipp.
• Beende ein Spiel jederzeit: Dann entscheidet der aktuelle Punktestand.

FÜR DIE GANZE FAMILIE
• Eine kurze animierte Anleitung beim Start und klare Regeln mit Bildern, nur einen Tipp entfernt.
• Helles und dunkles Design.
• Sechs Sprachen: Englisch, Ukrainisch, Deutsch, Französisch, Italienisch und Spanisch.
• Funktioniert ab dem ersten Start komplett offline.
• Dein Spiel bleibt auf dem Gerät gespeichert, sodass du jederzeit weiterspielen kannst.

KEINE WERBUNG. KEINE DATEN.
Keine Werbung, keine In-App-Käufe, keine Konten und kein Tracking. Die App erhebt keinerlei Daten: Spiele und Einstellungen bleiben auf deinem Gerät.
```
